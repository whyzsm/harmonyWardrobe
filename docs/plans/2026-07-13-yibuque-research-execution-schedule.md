## 2. 逐周拆解

### W1　启动与物料定稿
**目标**：研究就绪、招募开闸、确认真机依赖状态。
**任务**
- [ ] 评审并冻结四份物料（知情同意 / 访谈提纲 / 可用性任务卡 / 筛查+问卷）。
- [ ] 开通招募渠道（见第 3.2 节），上线筛查问卷（腾讯问卷/问卷星）。
- [ ] 确认 W3 真机依赖状态（签名材料、调试包、可用真机清单）——填第 4 节排查表。
- [ ] 建立研究数据仓库（加密目录 + 去标识化命名规范，见第 5 节）。
- [ ] 招募启动：先锁 W2 访谈名单（n=12），同步收集 W3 可用性候选（需 HarmonyOS 真机，n=8–10）。
**产出**：冻结物料、招募渠道就位、W2 访谈排期表、依赖状态表。
**风险**：HarmonyOS 真机用户稀缺 → 见第 3.2 与第 4 节预案。

### W2　深度访谈执行
**目标**：完成 12 场访谈，沉淀主题与假设。
**任务**
- [ ] 执行 12 场半结构化访谈（60–75 min），录音+转录。
- [ ] 每日访谈后做轻量 memos + 初步编码（用分析框架编码本）。
- [ ] 招募不辍：持续补 W3 可用性候选与 W4 问卷样本池。
- [ ] 问卷走查：小样本试填（n=10）校准表述歧义。
**产出**：访谈转录稿、初始主题、三角验证候选假设、问卷定稿。
**风险**：主题未饱和 → 允许 W2 末追加 2–3 场。

### W3　真机可用性测试
**目标**：在真实/模拟设备上完成 8–10 场测试，拿到任务指标。
**任务**
- [ ] 安装调试包到 HarmonyOS 真机（或模拟器，见第 4 节）。
- [ ] 执行 8–10 场测试（60 min），记录完成率/时长/错误/SUS/严重度。
- [ ] 每日汇总问题清单，标注严重度（Nielsen 0–4）。
- [ ] 与 W2 主题做初步交叉（哪些被验证/被推翻）。
**产出**：任务绩效数据、SUS、严重度问题表、think-aloud 引语库。
**风险**：真机不足 → 启用模拟器兜底，并在报告中标注限制（不计入真机结论置信）。

### W4　态度问卷发放与回收
**目标**：回收 n≈200 有效问卷。
**任务**
- [ ] 正式发放问卷（渠道见 3.2），保留 1–1.5 周窗口。
- [ ] 监控配额达成（性别/年龄/细分/平台），对薄弱环节追加投放。
- [ ] 数据清洗：剔除无效（作答时长异常、规律作答），反向题（Q15）反向计分。
**产出**：结构化数据集、配额达成报告、描述性统计初稿。
**风险**：样本偏差 → 用配额看板实时纠偏，必要时延长窗口。

### W5　分析与结论
**目标**：三角验证，产出研究报告与迭代建议。
**任务**
- [ ] 定性主题分析定稿 + 定量统计（交叉表/t 检验/ANOVA）。
- [ ] 填三角验证矩阵（每个 RQ 是否一致、置信度）。
- [ ] 套用分析框架第 5 节模板产出《衣不缺用户研究结论》。
- [ ] 与 design/product 评审，排定迭代优先级与成功度量。
**产出**：研究结论文档、优先级建议、影响度量计划、研究仓库归档。
**决策门**：结论是否支撑首版假设修订？排入下个迭代。

## 3. 招募启动专项

### 3.1 目标与配额
引用物料配额看板：访谈 n=12（时尚爱好者 6 / 实用整理者 4 / 45+ ≥2 / 无障碍 ≥2，性别均衡）；可用性 n=8–10（需 HarmonyOS 真机，含 45+ ≥2、无障碍 ≥2）；问卷 n≈200（细分 100/80，45+ 30，无障碍 20，性别均衡）。

### 3.2 招募渠道（分平台策略）
**HarmonyOS 真机用户（稀缺，优先保 W3）**
- 花粉俱乐部 / 鸿蒙 Next 体验官社区发帖招募。
- 公司内部/同事及其家属中持 HarmonyOS 设备者（最直接可靠）。
- 本地穿搭/生活类微信群、闺蜜群定向邀请。

**泛用户（W2 访谈 / W4 问卷可用，含 iOS/Android 用于对比）**
- 朋友圈 + 社群转发筛查问卷（带激励）。
- 小红书 / 即刻 / 豆瓣穿搭小组（注意不过度集中于单一时尚窄圈，避免样本偏斜）。
- 线下：商场/写字楼快闪招募，专门补足 45+ 与无障碍细分。

> 原则：访谈与问卷允许非 HarmonyOS（态度/行为可迁移）；**可用性测试必须 HarmonyOS 真机或授权模拟器**，否则结论不计入真机置信。

### 3.3 激励
- 访谈/测试：等价 100–200 元礼品卡或现金。
- 问卷：小额红包抽奖（如 20 份 × 20 元），提升回收与完答率。
- 无障碍/老年参与者酌情提高，降低参与门槛（含交通补贴）。

### 3.4 招募节奏
- W1 第 1–2 天：渠道开通 + 筛查上线。
- W1 第 3–5 天：锁 W2 访谈 12 人；建立 W3 候选池（≥12 人，留淘汰余量）。
- W2 全程：滚动补员，保证 W3 前真机候选 ≥10 人。
- W4 第 1 天：问卷全量发放；第 7–10 天查配额缺口补投；第 10–12 天截止清洗。

### 3.5 筛查与排期流程
1. 候选填筛查问卷（materials D）→ 自动按配额分类。
2. 研究员/招募员 24h 内回访确认资格 + 发送知情同意书。
3. 用在线表格排期（时段/方式/设备要求）。
4. 测试前 1 天提醒；到场签到 + 签署知情同意。

### 3.6 招募追踪看板（研究员填写）
| 细分 | 目标 | 已筛查 | 已确认 | 已执行 | 缺口 | 备注 |
|---|---|---|---|---|---|---|
| 访谈-时尚爱好者 | 6 | | | | | |
| 访谈-实用整理者 | 4 | | | | | |
| 访谈-45+ | ≥2 | | | | | |
| 访谈-无障碍 | ≥2 | | | | | |
| 可用- HarmonyOS 真机 | 8–10 | | | | | 含 45+/无障碍 |
| 问卷-总 | ≈200 | | | | | 按模块配额 |

### 3.7 防偏差与伦理红线
- 排除竞品/调研从业者、近 3 月同类研究参与者（筛查 Q8）。
- 性别、年龄、细分按比例强制配额，不“方便抽样”。
- 所有参与者签署知情同意；可随时退出并删数据。
- 录音/笔记去标识化，与研究数据独立；不出现姓名/手机号。
- 不虚构任何用户记录或结论（沿用产品「数据真实性」原则）。

## 4. W3 真机/签名包依赖排查清单（唯一硬阻塞）
逐项确认，任一项未过则触发预案：
- [ ] 签名材料（signingConfig）是否已配置？　状态：___
- [ ] 调试包（HAP）是否可在目标真机安装？　状态：___
- [ ] 可用 HarmonyOS 真机数量与型号清单：___
- [ ] 若真机不足：模拟器/非真机方案是否可用？　状态：___
- [ ] 离线（飞行模式）下应用启动与保存是否验证通过？　状态：___

**预案**
- 真机 < 所需：先跑内部机/模拟器可行性测试，真机补测顺延，报告标注限制。
- 签名未就绪：W1 即提给构建/发布负责人排期，不阻塞 W1–W2 招募与访谈。

## 5. 数据管理合规
- 仓库：加密目录，按 `YYYYMMDD_类型_编号`（如 `20260715_IV_01`）去标识化命名。
- 分层：原始录音（限授权人员）、转录文本、编码表、统计数据集分离存储。
- 保留：录音研究结束后 12 个月销毁；匿名化结论可入研究仓库长期留存。
- 传输：仅通过受控渠道，禁止明文外发用户原声/原图。

---

## 6. 里程碑与决策门
- M1（W1 末）：物料冻结 + 招募开闸 + 依赖状态已知 → go/no-go。
- M2（W2 末）：访谈完成 + 主题初步 + 问卷定稿。
- M3（W3 末）：可用性数据可分析 + 真机结论置信已知。
- M4（W4 末）：n≈200 有效问卷 + 配额达标。
- M5（W5 末）：研究结论评审通过，迭代建议排入下个 sprint。
