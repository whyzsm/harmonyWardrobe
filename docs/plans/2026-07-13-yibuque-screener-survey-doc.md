## 0. 开场白（置于问卷首页，简短知情同意）
> 你好，我们在为本地优先的衣橱 App「衣不缺」做用户研究，想先花 2 分钟了解你的情况，以便匹配合适的研究形式。参与研究会录音/录屏，资料去标识化、加密保存，你可随时退出。本问卷仅用于筛选，约 2 分钟。

## 1. 题面明细

### Q1 年龄
- 题型：单选（必答）
- 题干：你的年龄段是？
- 选项：
  1. 18–30 岁
  2. 31–45 岁
  3. 46–60 岁
  4. 60 岁以上
  5. 不愿透露
- 配额标记：`age`（用于细分分层）

### Q2 性别
- 题型：单选（必答）
- 题干：你的性别是？
- 选项：女 / 男 / 其他 / 不愿透露
- 配额标记：`gender`

### Q3 主力手机平台
- 题型：单选（必答）
- 题干：你平时主力使用的手机系统是？
- 选项：
  1. HarmonyOS / 鸿蒙
  2. iOS
  3. Android 其他品牌
  4. 其他
- 配额标记：`platform`（**HarmonyOS = 可用性测试优先候选**）

### Q4 自我定位（管理衣服的方式）
- 题型：单选（必答）
- 题干：你如何评价自己管理衣服/穿搭的方式？
- 选项：
  1. 时尚爱好者：常关注穿搭、买得多、爱记录
  2. 实用整理者：更看重整齐、好找、少麻烦
  3. 两者都有 / 都不太算
- 配额标记：`segment`（时尚爱好者 / 实用整理者）

### Q5 衣橱类 App 使用经历
- 题型：单选（必答）
- 题干：过去 3 个月，你是否用过衣橱 / 穿搭 / 记账类 App？
- 选项：是，常用 / 是，偶尔 / 否
- 配额标记：`app_exp`

### Q6 数码熟练度
- 题型：量表（必答，1 不熟 – 5 很熟）
- 题干：请评价你自己的数码产品熟练程度。
- 选项：1 / 2 / 3 / 4 / 5
- 配额标记：`tech`

### Q7 用机困扰
- 题型：多选（必答）
- 题干：你或家人是否有以下用手机时的困扰？（可多选）
- 选项：
  1. 看不清小字
  2. 点不准小按钮
  3. 对复杂流程容易迷路
  4. 无
  5. 不愿透露
- 配额标记：`a11y`（选 1/2/3 任一 → 纳入**无障碍细分候选**）

### Q8 排除项
- 题型：多选（必答）
- 题干：请确认你是否符合以下任一情况（符合请勾选）：
- 选项：
  1. 本人任职于竞品公司 / 用户研究 / 市场调研行业
  2. 近 3 个月参与过同类衣橱 / 穿搭产品的研究
  3. 以上都不是（请选此项若无不适用）
- **逻辑（关键）**：若 Q8 勾选了「1」或「2」→ **跳至结束页**（文案见第 3 节），不进入后续题。
- 注意：选项 3 为「无」，用于区分「未选 1/2」与「主动确认无」。导出时以「选了 1 或 2」判定剔除。

### Q9 希望参与的形式
- 题型：多选（必答）
- 题干：你愿意参与哪种研究形式？（可多选）
- 选项：
  1. 深度访谈（约 60 分钟）
  2. 可用性测试（约 60 分钟，需 HarmonyOS 设备）
  3. 填写问卷（约 10 分钟）
- 配额标记：`form`（用于任务分派；选「可用性测试」且 Q3=HarmonyOS 者优先排 W3）

### Q10 联系方式
- 题型：填空（必答）
- 题干：方便我们联系你的方式（微信 / 手机，仅用于本研究排期）：
- 占位提示：如 微信xxx 或 手机13xxxx
- 隐私提示：仅研究员可见，不与研究资料一同存储。

### Q11 可参与时段 / 备注
- 题型：填空（选填）
- 题干：你方便的时间段，或其他想说明的（选填）：

## 3. 逻辑与配额设置指引

### 3.1 跳题逻辑（两平台均支持「按选项跳题」）
- 在 Q8 上设置：选中选项 1 或 2 → 跳转至「排除结束页」。
- 其余题顺序作答，无需跳题。

### 3.2 配额设置
- **问卷星**：用「配额」功能，按 `age`+`gender`+`segment` 设上限（参考执行排期 3.6 看板）。达到上限后该组合自动停止收集。
- **腾讯问卷**：无内建配额上限，改用「导出后按追踪看板分类」+ 人工监控；或借助「白名单/分批链接」控制。
- 关键配额门槛：W3 可用性测试需 **HarmonyOS 真机 ≥10 名候选**（Q3=HarmonyOS 且 Q9 含「可用性测试」）；45+（Q1=46–60/60+）与无障碍（Q7 选 1/2/3）强制保留余量。

### 3.3 防偏差
- Q8 排除项必答且强制跳题，确保竞品/调研从业者不进入池。
- 不设置「提交即抽奖」的强诱导，避免为拿奖乱填；抽奖在正式研究环节发放。

## 4. 导出与分类（对接追踪看板）
- 导出字段建议：`age, gender, platform, segment, app_exp, tech, a11y, form, 联系方式`。
- 每日导出 → 按执行排期 3.6 看板填「已筛查 / 已确认 / 已执行」。
- 分类规则：
  - 访谈池：Q9 含「深度访谈」，按 segment 与 age 平衡取 12 人。
  - 可用池：Q9 含「可用性测试」且 Q3=HarmonyOS，取 ≥10 人（含 45+ ≥2、a11y ≥2）。
  - 问卷池：Q9 含「填写问卷」+ 公开投放补充，目标 ≈200。
