- 验收专家：奚顺畅（UX 体验专家）
- 基线：`docs/qa/manual-test-script.md`
- 代码范围：`entry/src/main/ets`（pages / components / app）
- 验收方式：代码静态走查（路由、文案、入口、空/加载/错误态、保存按钮一致性）+ 标注需真机验证项

## 三、偏差清单（建议修复，非阻塞）

- **D1（术语）**：拍照录入页模式标签 `单品/试穿/吊牌` 与快捷面板 `衣柜/逛店/穿搭`、导航 `穿搭/我的` 不统一；建议改为 `衣橱/美搭/逛店`（或沿用`衣柜/穿搭/逛店`），消除「吊牌」这类令人困惑的词。
- **D2（保存文案）**：拍照录入页美搭保存按钮 `保存试穿` 应统一为 `保存美搭`（与 OutfitEditPage 一致）。
- **D3（保存文案·较重）**：拍照录入页店铺保存按钮 `保存吊牌` 应统一为 `保存记录`/`保存逛店`（与 StoreVisitEditPage 一致）；「吊牌」易让用户误以为在存商品吊牌而非逛店记录。
- **D4（保存文案·轻微）**：拍照录入页 `保存衣服` 与衣物编辑页 `保存衣物` 统一为同一词（建议 `保存衣物`）。
- **D5（空态组件）**：建议统一空态为共享 `EmptyState` 组件或统一 builder 规范，避免衣柜/穿搭/逛店/心愿四处风格与文案差异。
- **D6（死代码/入口）**：`AppTopBar` 未被引用；基线 L57 描述的顶部右侧「我的」入口未实现。若产品接受「仅底部进入我的」，可删除 `AppTopBar` 并在文档注明；若需顶部入口则接上。

## 四、需真机验证项（🔍）

1. 相机/相册拉起（CaptureEditPage、各 EditPage 的拍照/选图）真实可用、权限失败有提示。
2. 启动初始化、各列表加载、保存中、搜索骨架屏在真机的中文渲染与转场手感。
3. 触达区域 ≥44 的真机实测（快捷面板行动卡 78、底部 tab、保存按钮均声明 ≥44，需实测）。
4. 离线（飞行模式）新增/编辑后重启回显（基线前置条件）。
5. 空态「点底部相机」指引在真机主 tab 时底部栏确实可见、可点。
