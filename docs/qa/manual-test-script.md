# 衣不缺手工 QA 脚本

## 前置条件

- 使用 `scripts/emulator-debug.sh` 进入模拟机调试环境并安装启动应用；多设备时通过 `HDC_TARGET=<target>` 指定模拟器。
- 关闭网络或进入飞行模式，确认应用仍可启动和保存数据。
- 离线状态下完成新增、编辑和重启回显检查。
- 准备至少 3 张本地相册图片，用于衣服、美搭和逛店记录。

## App 壳层

- 启动后首页不自绘状态栏；系统状态栏下方直接显示全宽搜索框，不显示额外页面标题或右上角相机入口。
- 底部主导航为深色浮动胶囊：`穿搭 / 衣柜 / 相机 / 逛街 / 我的`；中间相机只显示图标，不显示“拍照”文字，冷启动默认进入 `穿搭`。
- 点击底部 `我的` 可进入个人信息页。
- 点击底部相机打开快捷面板，入口从上到下为 `穿搭`、`逛店`、`衣柜`，说明分别为 `新增穿搭`、`新增逛店记录`、`新增衣物`。
- 快捷面板的三个动作是大行入口，包含标题和说明，触达区域不小于 44，点击后直接打开对应新增编辑页。
- 快捷面板可点击遮罩或取消关闭。
- 进入对应新增页面后，仍可通过页面内拍照或相册入口补充对应记录。
- 底部当前 tab 有清晰选中指示，点击 tab 或 `+` 有轻量按压反馈。

## 衣柜

- 进入 `衣柜` 后顶部依次显示全宽搜索框和横向分类胶囊，不显示标题、数量摘要或额外区块标题。
- 搜索框使用浅灰边框与系统搜索图标，键盘搜索键可进入搜索结果页。
- 分类选中态为黑色底、白色图标和文字，未选中态为白底浅灰边框。
- 分类为 `全部 / 上衣 / 裤装 / 裙装`，首屏完整显示，不出现其它旧筛选。
- 衣物列表使用双列原生瀑布流；卡片图片左上角显示分类图标，图片下标题最多两行，不提供收藏或社交动作。
- 点击任意真实衣物卡片进入对应衣物详情，不进入拍照或编辑页面。
- 长按衣物卡片图片并松手，图片上的深色蒙层和居中 `删除衣物` 按钮继续显示；点蒙层空白处关闭，取消确认后记录保留，确认后卡片和本地照片删除，关联穿搭解除该单品。
- 通过相机入口选择图片后归类为 `衣橱`，自动生成衣物名称；名称、分类、备注和购买信息都可选填或修改。
- 添加衣服页应为图片优先表单：照片入口明显；未选图片时保存按钮提示 `先添加照片`，选图后可保存；字段只显示中文标签，不出现 `name / 衣物名称`、`category / 分类`、`purchase / 购买信息` 等调试式文案。
- 添加衣服页分类选中态为黑色胶囊，不使用蓝色主选中态；保存按钮为黑色胶囊 `保存衣服`。
- 衣物卡片应显示衣物名称和分类，不只显示序号。
- 编辑刚新增的衣物，修改名称或备注后保存，列表回显更新。
- 空态文案应引导用户通过底部相机添加。

## 美搭

- 点击底部 `穿搭` 进入穿搭页，不通过衣柜页二级 tab 进入。
- 顶部分类显示 `全部` 和 SQLite 中保存的分类，默认没有 `逛店`；分类较多或名称较长时可横向滚动且文字不重叠。
- `全部` 包含未分类穿搭，顶部不单独提供 `未分类` 筛选。
- 通过相机入口选择图片后归类为 `美搭`，图片必填；美搭名称、关联衣物和备注都可不填，未填写名称时保存为 `穿搭`，不拼接日期时间；编辑历史自动名称时输入框也不显示日期时间。
- 新增穿搭默认选中 `通勤`；已有分类可以同时选中多个，再次点击可取消单项。编辑已有穿搭时保持其全部分类。也可手动输入一个额外分类；取消或保存失败时，新名称不进入分类列表，成功保存后再次新增可以选择该分类。
- 穿搭编辑页的每个已保存分类胶囊右侧显示 `×`，位置与常逛商圈标签一致；穿搭列表和编辑页均不显示独立分类管理按钮或弹层。点击 `×` 删除空分类；删除已使用分类需二次确认，确认后不删除穿搭和照片，只移除该项分类关联，其它已选分类保留，相关穿搭继续出现在 `全部` 中。
- 创建美搭页应显示 `美搭信息（选填）`、`美搭名称，可不填`、`备注` 等中文字段，保存按钮为黑色胶囊。
- 保存后回到 `穿搭`，卡片显示照片或柔和占位。
- 长按穿搭卡片图片并松手，图片上的深色蒙层和居中 `删除穿搭` 按钮继续显示；点蒙层空白处关闭，取消确认后记录保留，确认后卡片和照片删除，已有穿着记录保留但解除关联。
- 底部导航按截图显示 `穿搭`，编辑和保存流程内继续使用 `美搭` 或 `搭配`。

## 逛店

- 进入 `逛店` tab，默认展示逛店记录列表或空态。
- 逛店空态应像一个可行动入口，文案指向可见的相机入口；搜索无结果时应显示 `没有找到相关逛店记录`，不能误提示“还没有逛店记录”。
- 页面显示逛店记录数量；搜索时显示匹配条数。
- 通过相机入口选择图片后归类为 `店铺`，新增逛店记录。
- 记录逛店页应显示 `店铺信息`、`地址或商圈`、`试穿备注` 等中文字段，保存按钮为黑色胶囊。
- 填写店铺名、地址/商圈、日期、备注并选择图片，保存后回到 `逛店`。
- 逛店卡片展示店铺名、日期、地址/商圈、图片或 `店` 占位，备注最多两行。
- 点击逛店详情主图进入全屏等比预览；多图可左右滑动，当前序号与关闭操作可见。
- 长按逛店卡片图片并松手，图片上的深色蒙层和居中 `删除逛店记录` 按钮继续显示；点蒙层空白处关闭，取消确认后记录保留，确认后该记录和照片删除，门店资料保留。
- 搜索店铺名、地址/商圈或备注，结果应正确过滤。

## 我的

- 点击顶部右侧头像/`我的`。
- 页面显示头像占位、`身高`、`体重`、`腰围` 和 `设置`。
- 输入合法数值并保存，退出再进入后可以回显。
- 输入负数或非数字时，字段附近出现错误提示，保存按钮禁用。
- 保存成功后显示 `已保存个人信息`。
- 保存按钮有 `保存中...` 状态，重复点击不会产生明显异常。

## 搜索和旧概念

- 搜索结果展示类型应为 `衣物`、`美搭`、`逛店记录`、`店铺` 等用户可理解文案。
- 主流程不可见 `首页` 推荐流或 `心愿单` 主入口；衣柜页只显示衣物浏览、搜索和分类内容。
- 可达页面不可见点赞、收藏、评论、关注等社交动作。

## 视觉验收

- 主操作按钮是黑色胶囊按钮。
- 卡片大圆角，图片为圆角，不出现直角大图。
- 背景轻、留白充足，不呈现后台管理风或社交推荐流。
- 首页精致感来自图片、留白、柔和卡片和轻动效，不使用大面积粉色、花哨装饰或女性刻板化图形。
- 主要触达区域高度不小于 44。
- 加载、错误、重试、搜索等用户可见文案使用中文，不出现 `loading /`、`error /`、`retry`、`search` 这类调试式文案。
